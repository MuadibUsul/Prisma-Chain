## 1. What is enforced

| roadmap item | implementation |
|---|---|
| model manifest | `manifest.json` schema v1 (model/spec, GraphIDV2, PolicyID, digests, per-file sha256+bytes), written by `model build-manifest` |
| checkpoint hash | every listed file is re-hashed on verify; byte size cross-checked |
| profile binding | `graph.json` must recompute to the manifest's GraphIDV2 and the descriptor's PolicyID |
| PolicyID | compared against the descriptor and (by default) the frozen `eb9a9fef…` |
| GraphID/profile | recomputed with the worker's own canonical encoder (see §2) and required to equal `8fb86087…` |
| download | `model install` from a directory or URL base, manifest first |
| resume | partial downloads continue with HTTP `Range`; the resumed transfer is reported |
| cache | content-addressed blob cache (`.cache/<sha256>`), several profile versions side by side |
| corruption detection | mismatch → the artifact is **quarantined** (`*.quarantined-<stamp>` + `.reason`) and the command fails; nothing unverified reaches an execution path |

Only the frozen profile is supported: a profile whose identities are not
the frozen ones is refused (arbitrary models are explicitly out of scope
for the public alpha).

## 2. The GraphIDV2 mirror (and why it is safe)

A worker host has the worker package and the binaries, not the research
tree — so the worker carries its own implementation of the frozen canonical
encoder (canonical CBOR: `_head`/major bytes, maps sorted by encoded key
bytes, bool/None refused) plus the V2 domain string and
`sha256(DOMAIN_GRAPH_V2 ‖ encode_canonical(graph))`.

That mirror is pinned by tests against the frozen source of truth on every
run: `test_graphid.py` imports `compute/canonical/python/canonical_ref.py`
and `tools/f5c_bundle_v2.py` from the repository and asserts equality for
15 value shapes, for `hash_bytes`, for the domain string, and for the
frozen graph — `testdata/f5c_qwen3_block_v2.json` must compute to
`8fb86087697e…` / `eb9a9fef403c…` through both implementations. Drift fails
CI (the worker job runs in CI).

## 4. Definition of Done check

```text

    every file, GraphIDV2 and PolicyID; the frozen identities are required
corruption detected before any execution                yes — tamper test + real run:
    quarantine + hard error, exit 1
```
