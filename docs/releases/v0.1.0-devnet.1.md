# Prisma Chain v0.1.0-devnet.1

本版本是**单机本地开发网预览版**，用于运行和审查链上计算协议与统一 API 的闭环。它不是开放测试网，也不提供有真实货币价值的代币。

## 已实现

- Cosmos SDK + CometBFT 本地链、测试 $PRSM、模型登记、任务托管、工作者保证金、挑战、结算、退款与重复付款拦截。
- 有界整数 VM 的可复算任务和交互式挑战；本地脚本覆盖正常结果、错误结果及假挑战抢占。
- 轻量任务的工作者／网关双签收据、链上计费与剩余托管款退款。工作者可用隔离的**仅供开发网使用**的链密钥卷提交结果。
- 统一 `POST /v1/inference` 和 `GET /v1/tasks/{task_id}`：签名交付、链状态与账单、持久化收据，以及失败或网关重启后的后台提交重试。
- Tier 0 相对隐私提示、签名能力公告、探测路由与租约防旧版本执行。

## 快速运行

需要 Docker Compose 和 Python 3.10+。在仓库根目录执行：

```sh
python -m pip install -e './network[chain,model]'
python deploy/init_devnet.py
docker compose -f deploy/compose.yaml up --build -d
python deploy/smoke.py
```

`init_devnet.py` 只在首次运行时生成本地密钥；已有 `deploy/.env` 时不要再次运行。详细命令见 [本地部署说明](../../deploy/README.md)。需要检查链上正常、欺诈和结算路径时，可运行：

```sh
python deploy/compute_smoke.py --scenario honest --check-gateway
python deploy/compute_smoke.py --scenario fraud --check-gateway
python deploy/compute_smoke.py --scenario fraud-race --check-gateway
python deploy/funded_api_smoke.py
```

这些命令使用本地测试币并创建新的任务与测试账户；`funded_api_smoke.py` 使用合成模型，不调用付费 GPU。开发网测试账户和密钥不能用于主网或真实资产。

## 本版验收证据

- `python -m pytest network/tests -q`：21 项通过。
- `python deploy/smoke.py --no-chain`：本地容器的签名模拟交付、故障重试与未注资状态通过。
- `python deploy/funded_api_smoke.py`：真实本地链任务 23 首次收据提交故意失败，网关随后自动重试，任务经两名监控者确认后结算；2 个输出 token 收费 2000 uprsm，退款 8000 uprsm。
- `python deploy/worker_signer_smoke.py`：运行中的工作者用独立测试密钥卷提交任务 21 收据，重复提交幂等，双监控确认并结算。

## 已知限制

- Compose 默认使用未注资的确定性 mock 模型；Qwen3-14B／32B 的真实跨机推理和性能验收未完成。RunPod GPU 目前保持停止。
- 只有一个本地验证者；独立运营者、至少七验证节点、开放节点准入和生产密钥管理均未验收。节点公钥、账户和允许的主机仍需预置。
- 监控者与挑战交易由测试脚本驱动，尚无可独立运行、可对抗部署的监控网络；未完成独立安全审计。
- Tier 0 只承诺相对隐私，不是密码学秘密共享；本地 HTTP 配置不提供传输保密。
- 仓库尚未选择和发布源码许可证。源码可读取，但本版本**不声明已完成开源授权**。

本版代码基于提交 `085ffd3` 的功能；发布说明随版本提交。后续目标仍是可由独立运营者接入的完整开放测试网。
